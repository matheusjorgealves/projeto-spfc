# SPFC - Página Web Temática

Projeto de site temático desenvolvido com foco em prática de desenvolvimento front-end utilizando HTML e CSS.

O objetivo do projeto foi trabalhar conceitos de estruturação semântica, estilização visual e organização de layout, criando uma página inspirada no São Paulo Futebol Clube.

---

## Tecnologias utilizadas

- HTML5
- CSS3

---

## Conceitos aplicados

- Estrutura semântica
- Flexbox
- Variáveis CSS (`:root`)
- Pseudo-classes
- Gradientes
- Fontes personalizadas
- Organização visual de layout
- Estilização de imagens e containers

---

## Funcionalidades

- Navegação entre seções da página
- Layout centralizado
- Estilização temática inspirada no SPFC
- Efeitos visuais com `hover`
- Organização de conteúdo em seções

---

## Observações importantes

Este projeto foi desenvolvido **apenas para telas de notebook/desktop**.

Atualmente o site **não possui responsividade para dispositivos móveis**, portanto a experiência em celulares e telas menores pode apresentar:
- quebras de layout;
- elementos desproporcionais;
- problemas de alinhamento.

A responsividade será implementada futuramente conforme a evolução do projeto.

---

## Objetivo do projeto

Projeto criado com fins de estudo e prática de:
- HTML semântico;
- estilização com CSS;
- organização visual;
- construção de layouts para web.
